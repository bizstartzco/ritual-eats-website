# Ritual Eats — website preview

**Live preview:** https://bizstartzco.github.io/ritual-eats-website/

This is the working preview of the new Ritual Eats website. It updates every time a change is
pushed here, so the link above always shows the latest version. Open it on a laptop for the full
animated experience, then on your phone to see the mobile layout.

Progress by date is in [PROGRESS.md](PROGRESS.md). Technical notes for whoever hosts the site are
in [DEVELOPMENT.md](DEVELOPMENT.md).

## What is in this version

- A single scrolling page: hero, kitchen story, how a burger is made, the six signature burgers,
  sides and shakes, reviews, hours and address, booth booking, and a closing call to action.
- The hero burger travels the whole page as you scroll, in 3D, and lands in a ring at the end.
- Live "Open now / Closed" badge, hours table and tonight's special, all driven by the clock.
- A working order basket with pickup or delivery, quantities and totals.
- A booth booking form that only offers times inside opening hours.
- The Ritual Eats logo and colours (cream #FCE0BC, rust #9C2C0C) throughout.
